# Key House (Кілт үйі) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Kahoot-style multiplayer 2D browser game: up to 30 students join with a PIN, walk around a two-floor pixel-art house, answer one 4-option question per room to earn keys, and are ranked by keys then time; a host creates, starts, watches and stops the game.

**Architecture:** Static client (Vite + TypeScript + Phaser 3) deployed to Vercel talks over WebSocket to a Cloudflare Worker; each game PIN maps to one authoritative Durable Object (`GameRoom`) holding all state and the secret answers. Pure, unit-tested game logic lives in `server/src/game.ts`; geometry, protocol and ranking live in `shared/` and are imported by both sides via relative paths so server validation and client prediction use the same code.

**Tech Stack:** TypeScript 5.9.3, Phaser 3.90.0, Vite 7.3.7, Vitest 3.2.7, Wrangler 4.147.0 + `@cloudflare/workers-types` 5.20261006.1, Playwright 1.63.0, Node 24 (global `WebSocket`/`fetch`).

**Spec:** `docs/superpowers/specs/2026-10-06-key-house-design.md`

## Global Constraints

- Max players per game: **30**; characters: **25** (indices 0–24); name: **1–16** characters after trimming, unique case-insensitively (`toLocaleLowerCase`).
- PIN: **6 digits** (100000–999999). Countdown: **3000 ms**. Default time limit **10 min**, allowed **1–60 min**.
- Map tile: **32 px**. Walk speed: **160 px/s**. Server tick / snapshot rate: **100 ms**. Interact radius: **1.5 tiles (48 px)** from the pedestal centre.
- Ranking: keys desc → `lastKeyAt` (whole seconds since game start, `Math.floor`) asc → equal = shared place, standard competition numbering (1, 2, 2, 4). Zero-key players share one place.
- One attempt per room. Floor 2 unlocks when all 5 floor-1 rooms are answered (right or wrong).
- Game ends when (a) every **online** `playing` player has finished and at least one has finished, (b) time runs out, or (c) the host stops it.
- The correct answer index never leaves the server. Question text is single-language; **every UI string goes through `t()`** with `kk`, `ru`, `en` dictionaries (default `kk`).
- No external image/audio assets: all pixel art drawn on canvas in code, all sounds synthesised with WebAudio. Font: Google "Rubik" (supports Kazakh letters ә ғ қ ң ө ұ ү һ і).
- Any player-supplied text inserted into HTML goes through `escapeHtml`.
- Imports between packages use **relative paths** (`../../shared/src/...`); there is no `@kh/shared` package.
- Exact dependency versions above; install with `npm i -E`.
- Git commits end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

2. **Player refreshes the page mid-game** — must come back with the same progress and the *same* assigned question for a room they had opened. Pinned by `round-trips through toData/fromData…` (Task 5) and the reload step in the e2e test (Task 14).
3. **Host refreshes the host page mid-game** — must see the same PIN and live table. Pinned by the smoke script host-reconnect step (Task 6) and the e2e host reload step (Task 14).

`shared/src/ranking.ts`:

```ts
export interface RankInput {
  id: string;
  name: string;
  character: number;
  keys: number;
  /** Whole seconds since game start when the last key was earned; null when no keys. */
  lastKeyAt: number | null;
}

export type RankedPlayer = RankInput & { place: number };

/** Negative when `a` ranks higher. 0 means a true tie (same place). */
export function compareRank(a: RankInput, b: RankInput): number {
  if (a.keys !== b.keys) return b.keys - a.keys;
  // Equal keys > 0 ⇒ both lastKeyAt are numbers; equal keys = 0 ⇒ both null ⇒ tie.
  return (a.lastKeyAt ?? 0) - (b.lastKeyAt ?? 0);
}

export function rank<T extends RankInput>(players: readonly T[]): (T & { place: number })[] {
  const sorted = [...players].sort((a, b) => compareRank(a, b) || a.name.localeCompare(b.name));
  const out: (T & { place: number })[] = [];
  sorted.forEach((player, i) => {
    const prev = out[i - 1];
    const place = prev && compareRank(prev, player) === 0 ? prev.place : i + 1;
    out.push({ ...player, place });
  });
  return out;
}
```

```ts
  const start: [number, number] = [Math.floor(from.x / TILE), Math.floor(from.y / TILE)];
  const seen = new Set([start.join(',')]);
  const queue = [start];
  while (queue.length) {
```

```ts
import { INTERACT_RADIUS, TILE } from './constants';

export type FloorId = 'lobby' | 'f1' | 'f2';
export const ROOM_IDS = [
  'f1r1', 'f1r2', 'f1r3', 'f1r4', 'f1r5', 'f2r1', 'f2r2', 'f2r3', 'f2r4', 'f2r5',
] as const;
export type RoomId = (typeof ROOM_IDS)[number];
export type Theme =
  | 'library' | 'kitchen' | 'living' | 'bedroom' | 'bath'
  | 'lab' | 'music' | 'games' | 'observatory' | 'studio';

export interface Point { x: number; y: number }
/** Rectangle in tile units. */
export interface Rect { x: number; y: number; w: number; h: number }
export interface RoomDef {
  id: RoomId;
  floor: 'f1' | 'f2';
  theme: Theme;
  rect: Rect;
  door: Point;
  pedestal: Point;
}
export interface GameMap {
  id: FloorId;
  width: number;
  height: number;
  /** tiles[y][x]: # wall, . hall, , room floor, D door, K pedestal, f furniture, S stairs, B bench, L screen */
  tiles: string[][];
  /** Pixel position. */
  spawn: Point;
  rooms: RoomDef[];
  stairs: Rect | null;
}

const BLOCKING = new Set(['#', 'K', 'f', 'B', 'L']);
/** Half extents (px) of the player's feet box around its (x, y) feet point. */
export const HITBOX = { hw: 10, hh: 6 } as const;

export function isRoomId(v: unknown): v is RoomId {
  return typeof v === 'string' && (ROOM_IDS as readonly string[]).includes(v);
}
export function tileCenter(tx: number, ty: number): Point {
  return { x: (tx + 0.5) * TILE, y: (ty + 0.5) * TILE };
}
export function isBlockingTile(ch: string): boolean {
  return BLOCKING.has(ch);
}
export function tileAt(map: GameMap, tx: number, ty: number): string {
  return map.tiles[ty]?.[tx] ?? '#';
}

function grid(w: number, h: number, ch: string): string[][] {
  return Array.from({ length: h }, () => Array.from({ length: w }, () => ch));
}
function fill(g: string[][], r: Rect, ch: string): void {
  for (let y = r.y; y < r.y + r.h; y++) for (let x = r.x; x < r.x + r.w; x++) g[y][x] = ch;
}
function contains(r: Rect, tx: number, ty: number): boolean {
  return tx >= r.x && tx < r.x + r.w && ty >= r.y && ty < r.y + r.h;
}

const FLOOR_W = 31;
const FLOOR_H = 19;
const ROOM_RECTS: Rect[] = [
  { x: 1, y: 1, w: 8, h: 6 },
  { x: 10, y: 1, w: 9, h: 6 },
  { x: 20, y: 1, w: 10, h: 6 },
  { x: 1, y: 12, w: 9, h: 6 },
  { x: 11, y: 12, w: 9, h: 6 },
];
const THEMES: Record<'f1' | 'f2', Theme[]> = {
  f1: ['library', 'kitchen', 'living', 'bedroom', 'bath'],
  f2: ['lab', 'music', 'games', 'observatory', 'studio'],
};
export const FLOOR_SPAWN = tileCenter(13, 9);
export const STAIRS_ARRIVAL = tileCenter(25, 9);

function buildFloor(floor: 'f1' | 'f2'): GameMap {
  const g = grid(FLOOR_W, FLOOR_H, '#');
  fill(g, { x: 1, y: 8, w: 29, h: 3 }, '.');
  const stairs: Rect = { x: 27, y: 8, w: 3, h: 3 };
  fill(g, stairs, 'S');
  const rooms = ROOM_RECTS.map((rect, i): RoomDef => {
    fill(g, rect, ',');
    const top = rect.y < 8;
    const cx = rect.x + Math.floor(rect.w / 2);
    const door = { x: cx, y: top ? rect.y + rect.h : rect.y - 1 };
    const pedestal = { x: cx, y: rect.y + Math.floor(rect.h / 2) };
    g[door.y][door.x] = 'D';
    g[pedestal.y][pedestal.x] = 'K';
    const fy = top ? rect.y : rect.y + rect.h - 1;
    for (const fx of [rect.x, rect.x + 1, rect.x + rect.w - 2, rect.x + rect.w - 1]) g[fy][fx] = 'f';
    return { id: `${floor}r${i + 1}` as RoomId, floor, theme: THEMES[floor][i], rect, door, pedestal };
  });
  return { id: floor, width: FLOOR_W, height: FLOOR_H, tiles: g, spawn: FLOOR_SPAWN, rooms, stairs };
}

function buildLobby(): GameMap {
  const W = 24, H = 15;
  const g = grid(W, H, '#');
  fill(g, { x: 1, y: 1, w: W - 2, h: H - 2 }, '.');
  fill(g, { x: 7, y: 1, w: 10, h: 3 }, 'L');
  for (const [x, y] of [[3, 5], [18, 5], [3, 10], [18, 10]]) fill(g, { x, y, w: 3, h: 1 }, 'B');
  return { id: 'lobby', width: W, height: H, tiles: g, spawn: tileCenter(12, 8), rooms: [], stairs: null };
}

export const MAPS: Record<FloorId, GameMap> = {
  lobby: buildLobby(),
  f1: buildFloor('f1'),
  f2: buildFloor('f2'),
};

export const ROOMS = Object.fromEntries(
  [...MAPS.f1.rooms, ...MAPS.f2.rooms].map((r) => [r.id, r]),
) as Record<RoomId, RoomDef>;

export function roomAtTile(map: GameMap, tx: number, ty: number): RoomDef | null {
  return map.rooms.find((r) => contains(r.rect, tx, ty)) ?? null;
}
export function roomAt(map: GameMap, x: number, y: number): RoomDef | null {
  return roomAtTile(map, Math.floor(x / TILE), Math.floor(y / TILE));
}

export function canStand(map: GameMap, x: number, y: number): boolean {
  const x0 = Math.floor((x - HITBOX.hw) / TILE);
  const x1 = Math.floor((x + HITBOX.hw - 1) / TILE);
  const y0 = Math.floor((y - HITBOX.hh) / TILE);
  const y1 = Math.floor((y + HITBOX.hh - 1) / TILE);
  for (let ty = y0; ty <= y1; ty++) {
    for (let tx = x0; tx <= x1; tx++) if (isBlockingTile(tileAt(map, tx, ty))) return false;
  }
  return true;
}

/** Same rule on client and server: walls block, and an answered room can be left but not re-entered. */
export function moveAllowed(map: GameMap, from: Point, to: Point, answered: ReadonlySet<RoomId>): boolean {
  if (!canStand(map, to.x, to.y)) return false;
  const target = roomAt(map, to.x, to.y);
  if (target && answered.has(target.id) && roomAt(map, from.x, from.y)?.id !== target.id) return false;
  return true;
}

export function nearPedestal(room: RoomDef, x: number, y: number): boolean {
  const c = tileCenter(room.pedestal.x, room.pedestal.y);
  return Math.hypot(x - c.x, y - c.y) <= INTERACT_RADIUS;
}

export function onStairs(map: GameMap, x: number, y: number): boolean {
  return tileAt(map, Math.floor(x / TILE), Math.floor(y / TILE)) === 'S';
}
```

```ts
  serverNow: number;

export interface QuestionView { roomId: RoomId; q: string; options: string[] }

export type ClientMsg =
  | { t: 'join'; name: string; character: number; lang: Lang }
  | { t: 'resume'; token: string }
  | { t: 'host'; hostToken: string }
  | { t: 'move'; x: number; y: number; dir: Dir; moving: boolean }
  | { t: 'interact'; roomId: RoomId }
  | { t: 'answer'; roomId: RoomId; optionIndex: number }
  | { t: 'stairs' }
  | { t: 'spectate'; targetId: string | null }
  | { t: 'start' }
  | { t: 'stop' };

  | { t: 'welcome'; token: string; you: YouState; phase: PhaseInfo; roster: PublicPlayer[] }
  | { t: 'hostWelcome'; pin: string; timeLimitMin: number; phase: PhaseInfo; roster: PublicPlayer[]; ranking: RankedPlayer[] | null }

  | { t: 'roster'; players: PublicPlayer[] }

  | { t: 'answerResult'; roomId: RoomId; correct: boolean }
  | { t: 'ended'; ranking: RankedPlayer[] }

const isNum = (v: unknown): v is number => typeof v === 'number' && Number.isFinite(v);

export function parseClientMsg(raw: string): ClientMsg | null {
  if (raw.length > 2000) return null;
  let m: Record<string, unknown>;
  try {
    m = JSON.parse(raw);
  } catch {
    return null;
  }
  if (!m || typeof m !== 'object' || typeof m.t !== 'string') return null;
  switch (m.t) {
    case 'join':
      return isStr(m.name, 64) && Number.isInteger(m.character) && (LANGS as readonly unknown[]).includes(m.lang)
        ? { t: 'join', name: m.name, character: m.character as number, lang: m.lang as Lang }
        : null;
    case 'resume':
      return isStr(m.token, 64) ? { t: 'resume', token: m.token } : null;
    case 'host':
      return isStr(m.hostToken, 64) ? { t: 'host', hostToken: m.hostToken } : null;
    case 'move':
      return isNum(m.x) && isNum(m.y) && typeof m.dir === 'string' && DIRS.includes(m.dir) && typeof m.moving === 'boolean'
        ? { t: 'move', x: m.x, y: m.y, dir: m.dir as Dir, moving: m.moving }
        : null;
    case 'interact':
      return isRoomId(m.roomId) ? { t: 'interact', roomId: m.roomId } : null;
    case 'answer':
      return isRoomId(m.roomId) && Number.isInteger(m.optionIndex)
        ? { t: 'answer', roomId: m.roomId, optionIndex: m.optionIndex as number }
        : null;
    case 'stairs':
    case 'start':
    case 'stop':
      return { t: m.t };
    case 'spectate':
      return m.targetId === null || isStr(m.targetId, 64)
        ? { t: 'spectate', targetId: m.targetId as string | null }
        : null;
    default:
      return null;
  }
}
```

```ts
import { ROOM_IDS, type RoomId } from '../../shared/src/map';

export interface Question {
  q: string;
  options: string[];
  /** Index (0–3) of the correct option in `options`. Never sent to clients. */
  correct: number;
}
export type QuestionBank = Record<RoomId, Question[]>;

export function validateQuestions(raw: unknown): QuestionBank {
  if (!raw || typeof raw !== 'object') throw new Error('questions.json: a JSON object is expected');
  const errors: string[] = [];
  const bank = {} as QuestionBank;
  for (const id of ROOM_IDS) {
    const list = (raw as Record<string, unknown>)[id];
    if (!Array.isArray(list) || list.length === 0) {
      errors.push(`${id}: at least one question is required`);
      continue;
    }
    list.forEach((item: unknown, i) => {
      const where = `${id}[${i}]`;
      if (!item || typeof item !== 'object') {
        errors.push(`${where}: object expected`);
        return;
      }
      const { q, options, correct } = item as Record<string, unknown>;
      if (typeof q !== 'string' || !q.trim()) errors.push(`${where}.q: non-empty string required`);
      if (!Array.isArray(options) || options.length !== 4 || options.some((o) => typeof o !== 'string' || !o.trim())) {
        errors.push(`${where}.options: exactly 4 non-empty strings required`);
      }
      if (!Number.isInteger(correct) || (correct as number) < 0 || (correct as number) > 3) {
        errors.push(`${where}.correct: integer 0..3 required`);
      }
    });
    bank[id] = list as Question[];
  }
  if (errors.length) throw new Error(`questions.json is invalid:\n${errors.join('\n')}`);
  return bank;
}
```

```ts
/** Server never measures a move over less than this, so bunched packets are not punished. */
const MIN_MOVE_DT_MS = 100;
const MOVE_SLACK = 1.5;
const MOVE_SLACK_PX = 4;

export class Game {
  phase: Phase = 'LOBBY';
  countdownEndsAt: number | null = null;
  startedAt: number | null = null;
  endsAt: number | null = null;
  endedAt: number | null = null;
  readonly players = new Map<string, PlayerState>();

  constructor(
    readonly pin: string,
    readonly hostToken: string,
    readonly timeLimitMin: number,
    private readonly questions: QuestionBank,
    private readonly deps: GameDeps,
  ) {}

  static fromData(d: GameData, questions: QuestionBank, deps: GameDeps): Game {
    const g = new Game(d.pin, d.hostToken, d.timeLimitMin, questions, deps);
    g.phase = d.phase;
    g.countdownEndsAt = d.countdownEndsAt;
    g.startedAt = d.startedAt;
    g.endsAt = d.endsAt;
    g.endedAt = d.endedAt;
    for (const p of d.players) g.players.set(p.id, { ...p, online: false, moving: false });
    return g;
  }

  toData(): GameData {
    return {
      pin: this.pin,
      hostToken: this.hostToken,
      timeLimitMin: this.timeLimitMin,
      phase: this.phase,
      countdownEndsAt: this.countdownEndsAt,
      startedAt: this.startedAt,
      endsAt: this.endsAt,
      endedAt: this.endedAt,
      players: [...this.players.values()].map((p) => structuredClone(p)),
    };
  }

  // ---------- lobby ----------

  addPlayer(rawName: string, character: number, lang: Lang): { ok: true; player: PlayerState } | Fail {
    if (this.phase !== 'LOBBY') return fail('ALREADY_STARTED');
    const name = rawName.trim().replace(/\s+/g, ' ');
    const len = [...name].length;
    if (len < 1 || len > NAME_MAX) return fail('NAME_INVALID');
    if (!Number.isInteger(character) || character < 0 || character >= CHARACTER_COUNT) return fail('BAD_CHARACTER');
    if (this.players.size >= MAX_PLAYERS) return fail('GAME_FULL');
    const key = name.toLocaleLowerCase();
    for (const p of this.players.values()) if (p.name.toLocaleLowerCase() === key) return fail('NAME_TAKEN');
    const pos = this.jitter(MAPS.lobby.spawn);
    const player: PlayerState = {
      id: this.deps.newId(),
      token: this.deps.newId(),
      name,
      character,
      lang,
      online: true,
      status: 'lobby',
      floor: 'lobby',
      x: pos.x,
      y: pos.y,
      dir: 'down',
      moving: false,
      lastMoveAt: this.deps.now(),
      keys: 0,
      rooms: 0,
      lastKeyAt: null,
      answered: {},
      assigned: {},
      spectating: null,
    };
    this.players.set(player.id, player);
    return { ok: true, player };
  }

  resume(token: string): PlayerState | undefined {
    for (const p of this.players.values()) if (p.token === token) return p;
    return undefined;
  }

  setOnline(id: string, online: boolean): void {
    const p = this.players.get(id);
    if (!p) return;
    p.online = online;
    if (!online) p.moving = false;
    p.lastMoveAt = this.deps.now();
    this.checkAllDone();
  }

  // ---------- phases ----------

  start(): { ok: true } | Fail {
    if (this.phase !== 'LOBBY') return fail('WRONG_PHASE');
    if (this.players.size === 0) return fail('NO_PLAYERS');
    this.phase = 'COUNTDOWN';
    this.countdownEndsAt = this.deps.now() + COUNTDOWN_MS;
    return { ok: true };
  }

  stop(): { ok: true } | Fail {
    if (this.phase !== 'PLAYING' && this.phase !== 'COUNTDOWN') return fail('WRONG_PHASE');
    this.end();
    return { ok: true };
  }

  /** Advances timers. Returns true when the phase changed. */
  tick(): boolean {
    const now = this.deps.now();
    if (this.phase === 'COUNTDOWN' && this.countdownEndsAt !== null && now >= this.countdownEndsAt) {
      this.beginPlaying();
      return true;
    }
    if (this.phase === 'PLAYING' && this.endsAt !== null && now >= this.endsAt) {
      this.end();
      return true;
    }
    return false;
  }

  private beginPlaying(): void {
    this.phase = 'PLAYING';
    this.startedAt = this.countdownEndsAt;
    this.endsAt = this.startedAt! + this.timeLimitMin * 60_000;
    const now = this.deps.now();
    for (const p of this.players.values()) {
      const pos = this.jitter(FLOOR_SPAWN);
      Object.assign(p, { status: 'playing', floor: 'f1', x: pos.x, y: pos.y, moving: false, lastMoveAt: now });
    }
  }

  private end(): void {
    this.phase = 'ENDED';
    this.endedAt = this.deps.now();
    for (const p of this.players.values()) p.moving = false;
  }

  private checkAllDone(): void {
    if (this.phase !== 'PLAYING') return;
    const all = [...this.players.values()];
    const activeOnline = all.filter((p) => p.status === 'playing' && p.online);
    if (activeOnline.length === 0 && all.some((p) => p.status === 'finished')) this.end();
  }

  // ---------- actions ----------

  move(id: string, x: number, y: number, dir: Dir, moving: boolean):
    { ok: true } | { ok: false; fix: { floor: FloorId; x: number; y: number } } | null {
    const p = this.players.get(id);
    if (!p || this.phase === 'COUNTDOWN' || this.phase === 'ENDED') return null;
    const now = this.deps.now();
    const dt = Math.max(now - p.lastMoveAt, MIN_MOVE_DT_MS);
    const maxDist = (SPEED * dt * MOVE_SLACK) / 1000 + MOVE_SLACK_PX;
    const valid =
      Number.isFinite(x) && Number.isFinite(y) &&
      Math.hypot(x - p.x, y - p.y) <= maxDist &&
      moveAllowed(MAPS[p.floor], { x: p.x, y: p.y }, { x, y }, this.answeredSet(p));
    if (!valid) return { ok: false, fix: { floor: p.floor, x: p.x, y: p.y } };
    Object.assign(p, { x, y, dir, moving, lastMoveAt: now });
    return { ok: true };
  }

  stairs(id: string): { ok: true; floor: FloorId; x: number; y: number } | Fail {
    const p = this.players.get(id);
    if (!p || this.phase !== 'PLAYING' || p.status !== 'playing') return fail('WRONG_PHASE');
    if (!onStairs(MAPS[p.floor], p.x, p.y)) return fail('NOT_NEAR');
    if (p.floor === 'f1' && !this.floor2Unlocked(p)) return fail('FLOOR_LOCKED');
    p.floor = p.floor === 'f1' ? 'f2' : 'f1';
    p.x = STAIRS_ARRIVAL.x;
    p.y = STAIRS_ARRIVAL.y;
    p.moving = false;
    p.lastMoveAt = this.deps.now();
    return { ok: true, floor: p.floor, x: p.x, y: p.y };
  }

  interact(id: string, roomId: RoomId): { ok: true; question: QuestionView } | Fail {
    const p = this.players.get(id);
    if (!p || this.phase !== 'PLAYING' || p.status !== 'playing') return fail('WRONG_PHASE');
    const room = ROOMS[roomId];
    if (!room) return fail('BAD_REQUEST');
    if (p.answered[roomId]) return fail('ALREADY_ANSWERED');
    if (room.floor === 'f2' && !this.floor2Unlocked(p)) return fail('FLOOR_LOCKED');
    if (room.floor !== p.floor || !nearPedestal(room, p.x, p.y)) return fail('NOT_NEAR');
    const pool = this.questions[roomId];
    if (!pool?.length) return fail('NO_QUESTION');
    let a = p.assigned[roomId];
    if (!a) {
      a = { qIndex: Math.floor(this.deps.rng() * pool.length), order: this.shuffle([0, 1, 2, 3]) };
      p.assigned[roomId] = a;
    }
    const q = pool[a.qIndex];
    return { ok: true, question: { roomId, q: q.q, options: a.order.map((i) => q.options[i]) } };
  }

  answer(id: string, roomId: RoomId, optionIndex: number): { ok: true; correct: boolean; finished: boolean } | Fail {
    const p = this.players.get(id);
    if (!p || this.phase !== 'PLAYING' || p.status !== 'playing') return fail('WRONG_PHASE');
    if (!ROOMS[roomId] || !Number.isInteger(optionIndex) || optionIndex < 0 || optionIndex > 3) return fail('BAD_REQUEST');
    if (p.answered[roomId]) return fail('ALREADY_ANSWERED');
    const a = p.assigned[roomId];
    if (!a) return fail('NO_QUESTION');
    const correct = a.order[optionIndex] === this.questions[roomId][a.qIndex].correct;
    p.answered[roomId] = correct ? 'correct' : 'wrong';
    p.rooms += 1;
    if (correct) {
      p.keys += 1;
      p.lastKeyAt = this.elapsedSec();
    }
    let finished = false;
    if (p.rooms >= TOTAL_ROOMS) {
      const pos = this.jitter(MAPS.lobby.spawn);
      Object.assign(p, { status: 'finished', floor: 'lobby', x: pos.x, y: pos.y, moving: false, spectating: null });
      p.lastMoveAt = this.deps.now();
      finished = true;
    }
    this.checkAllDone();
    return { ok: true, correct, finished };
  }

  spectate(id: string, targetId: string | null): void {
    const p = this.players.get(id);
    if (!p || p.status !== 'finished') return;
    if (targetId === null) {
      p.spectating = null;
      return;
    }
    const t = this.players.get(targetId);
    if (t && t.status === 'playing') p.spectating = targetId;

      countdownEndsAt: this.countdownEndsAt,
      startedAt: this.startedAt,
      endsAt: this.endsAt,
      serverNow: this.deps.now(),
    };
  }

  roster(): PublicPlayer[] {
    return [...this.players.values()].map((p) => ({
      id: p.id,
      name: p.name,
      character: p.character,
      keys: p.keys,
      rooms: p.rooms,
      status: p.status,
      floor: p.floor,
      online: p.online,
      lastKeyAt: p.lastKeyAt,
    }));
  }

  you(p: PlayerState): YouState {
    return {
      id: p.id,
      name: p.name,
      character: p.character,
      keys: p.keys,
      rooms: p.rooms,
      answered: { ...p.answered },
      floor2Unlocked: this.floor2Unlocked(p),
      status: p.status,
      floor: p.floor,
      x: p.x,
      y: p.y,
    };
  }

  /** Which floor this player's screen shows (spectators see their target's floor). */
  viewFloor(p: PlayerState): FloorId {
    if (p.status === 'finished' && p.spectating) {
      const t = this.players.get(p.spectating);
      if (t && t.status === 'playing') return t.floor;
    }
    return p.floor;
  }

  snapshotFor(floor: FloorId): PosEntry[] {
    const out: PosEntry[] = [];
    for (const p of this.players.values()) {
      if (!p.online || p.floor !== floor) continue;
      out.push({ id: p.id, x: Math.round(p.x), y: Math.round(p.y), dir: p.dir, moving: p.moving, floor: p.floor });
    }
    return out;
  }

  ranking(): RankedPlayer[] {
    return rank(
      [...this.players.values()].map((p) => ({
        id: p.id, name: p.name, character: p.character, keys: p.keys, lastKeyAt: p.lastKeyAt,
      })),
    );
  }

  // ---------- helpers ----------

  private elapsedSec(): number {
    return Math.floor((this.deps.now() - (this.startedAt ?? this.deps.now())) / 1000);
  }

  private answeredSet(p: PlayerState): Set<RoomId> {
    return new Set(Object.keys(p.answered) as RoomId[]);
  }

  private jitter(base: Point): Point {
    return { x: base.x + (this.deps.rng() - 0.5) * 64, y: base.y + (this.deps.rng() - 0.5) * 40 };
  }

  private shuffle<T>(items: T[]): T[] {
    const a = [...items];
    for (let i = a.length - 1; i > 0; i--) {
      const j = Math.floor(this.deps.rng() * (i + 1));
      [a[i], a[j]] = [a[j], a[i]];
    }
    return a;
  }
}
```

```ts
import { DurableObject } from 'cloudflare:workers';
import questionsRaw from '../questions.json';
import { MAX_PLAYERS, TICK_MS } from '../../shared/src/constants';
import type { FloorId } from '../../shared/src/map';
import { parseClientMsg, type ClientMsg, type ServerMsg } from '../../shared/src/protocol';
import type { Env } from './env';
import { Game, type GameData, type GameDeps } from './game';
import { validateQuestions } from './questions';

const QUESTIONS = validateQuestions(questionsRaw);
const CLEANUP_AFTER_MS = 3 * 60 * 60 * 1000;
const MAX_MSGS_PER_SEC = 30;

type Conn = { kind: 'pending' } | { kind: 'player'; id: string } | { kind: 'host' };
interface Session { conn: Conn; windowStart: number; count: number }

export class GameRoom extends DurableObject<Env> {
  private game: Game | null = null;
  private sessions = new Map<WebSocket, Session>();
  private timer: ReturnType<typeof setInterval> | null = null;
  private readonly deps: GameDeps = {
    now: () => Date.now(),
    rng: Math.random,
    newId: () => crypto.randomUUID(),
  };

  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    ctx.blockConcurrencyWhile(async () => {
      const data = await ctx.storage.get<GameData>('game');
      if (data) this.game = Game.fromData(data, QUESTIONS, this.deps);
    });
  }

  // ---------- RPC from the Worker ----------

  async init(opts: { pin: string; timeLimitMin: number; hostToken: string }): Promise<boolean> {
    if (this.game && this.game.phase !== 'ENDED') return false;
    for (const ws of this.sessions.keys()) ws.close(1000, 'new game');
    this.sessions.clear();
    this.game = new Game(opts.pin, opts.hostToken, opts.timeLimitMin, QUESTIONS, this.deps);
    await this.persist();
    await this.ctx.storage.setAlarm(Date.now() + opts.timeLimitMin * 60_000 + CLEANUP_AFTER_MS);
    return true;
  }

  async info(): Promise<{ exists: false } | { exists: true; phase: Game['phase']; count: number; full: boolean }> {
    const g = this.game;
    if (!g) return { exists: false };
    return { exists: true, phase: g.phase, count: g.players.size, full: g.players.size >= MAX_PLAYERS };
  }

  async alarm(): Promise<void> {
    if (this.game && (this.game.phase === 'PLAYING' || this.game.phase === 'COUNTDOWN')) {
      await this.ctx.storage.setAlarm(Date.now() + 60 * 60 * 1000);
      return;
    }
    for (const ws of this.sessions.keys()) ws.close(1001, 'expired');
    this.sessions.clear();
    this.stopTimer();
    this.game = null;
    await this.ctx.storage.deleteAll();
  }

  // ---------- WebSocket ----------

  async fetch(_req: Request): Promise<Response> {
    const pair = new WebSocketPair();
    const [client, server] = Object.values(pair);
    server.accept();
    this.sessions.set(server, { conn: { kind: 'pending' }, windowStart: Date.now(), count: 0 });
    server.addEventListener('message', (ev) => this.onMessage(server, ev.data));
    server.addEventListener('close', () => this.onClose(server));
    server.addEventListener('error', () => this.onClose(server));
    this.ensureTimer();
    return new Response(null, { status: 101, webSocket: client });
  }

  private onMessage(ws: WebSocket, data: unknown): void {
    const s = this.sessions.get(ws);
    if (!s || typeof data !== 'string') return;
    const now = Date.now();
    if (now - s.windowStart >= 1000) {
      s.windowStart = now;
      s.count = 0;
    }
    if (++s.count > MAX_MSGS_PER_SEC) return;
    const msg = parseClientMsg(data);
    if (!msg) return;
    const game = this.game;
    if (!game) {
      this.send(ws, { t: 'error', code: 'PIN_NOT_FOUND' });
      ws.close(4004, 'no game');
      return;
    }
    try {
      this.handle(ws, s, game, msg);
    } catch (err) {
      console.error('message handling failed', err);
    }
  }

  private handle(ws: WebSocket, s: Session, game: Game, msg: ClientMsg): void {
    if (s.conn.kind === 'pending') {
      if (msg.t === 'join') {
        const r = game.addPlayer(msg.name, msg.character, msg.lang);
        if (!r.ok) return this.send(ws, { t: 'error', code: r.code });
        this.bindPlayer(ws, s, r.player.id);
        this.broadcastRoster();
        void this.persist();
      } else if (msg.t === 'resume') {
        const p = game.resume(msg.token);
        if (!p) return this.send(ws, { t: 'error', code: 'BAD_TOKEN' });
        for (const [other, os] of this.sessions) {
          if (other !== ws && os.conn.kind === 'player' && os.conn.id === p.id) {
            this.sessions.delete(other);
            other.close(4001, 'replaced');
          }
        }
        const before = game.phase;
        game.setOnline(p.id, true);
        this.bindPlayer(ws, s, p.id);
        this.broadcastRoster();
        if (game.phase !== before) this.afterPhaseChange();
      } else if (msg.t === 'host') {
        if (msg.hostToken !== game.hostToken) return this.send(ws, { t: 'error', code: 'BAD_HOST_TOKEN' });
        s.conn = { kind: 'host' };
        this.send(ws, {
          t: 'hostWelcome',
          pin: game.pin,
          timeLimitMin: game.timeLimitMin,
          phase: game.phaseInfo(),
          roster: game.roster(),
          ranking: game.phase === 'ENDED' ? game.ranking() : null,
        });
      }
      return;
    }

    if (s.conn.kind === 'host') {
      if (msg.t !== 'start' && msg.t !== 'stop') return;
      const r = msg.t === 'start' ? game.start() : game.stop();
      if (!r.ok) return this.send(ws, { t: 'error', code: r.code });
      this.afterPhaseChange();
      return;
    }

    const id = s.conn.id;
    switch (msg.t) {
      case 'move': {
        const r = game.move(id, msg.x, msg.y, msg.dir, msg.moving);
        if (r && !r.ok) this.send(ws, { t: 'teleport', ...r.fix });
        return;
      }
      case 'interact': {
        const r = game.interact(id, msg.roomId);
        this.send(ws, r.ok ? { t: 'question', question: r.question } : { t: 'error', code: r.code });
        if (r.ok) void this.persist();
        return;
      }
      case 'answer': {
        const before = game.phase;
        const r = game.answer(id, msg.roomId, msg.optionIndex);
        if (!r.ok) return this.send(ws, { t: 'error', code: r.code });
        const p = game.players.get(id)!;
        this.send(ws, { t: 'answerResult', roomId: msg.roomId, correct: r.correct });
        this.send(ws, { t: 'you', you: game.you(p) });
        if (r.finished) this.send(ws, { t: 'teleport', floor: p.floor, x: p.x, y: p.y });
        this.broadcastRoster();
        if (game.phase !== before) this.afterPhaseChange();
        else void this.persist();
        return;
      }
      case 'stairs': {
        const r = game.stairs(id);
        if (!r.ok) return this.send(ws, { t: 'error', code: r.code });
        this.send(ws, { t: 'teleport', floor: r.floor, x: r.x, y: r.y });
        this.broadcastRoster();
        return;
      }
      case 'spectate':
        game.spectate(id, msg.targetId);
        return;
    }
  }

  private bindPlayer(ws: WebSocket, s: Session, id: string): void {
    const game = this.game!;
    const p = game.players.get(id)!;
    s.conn = { kind: 'player', id };
    this.send(ws, { t: 'welcome', token: p.token, you: game.you(p), phase: game.phaseInfo(), roster: game.roster() });
    if (game.phase === 'ENDED') this.send(ws, { t: 'ended', ranking: game.ranking() });
  }

  private onClose(ws: WebSocket): void {
    const s = this.sessions.get(ws);
    if (!s) return;
    this.sessions.delete(ws);
    const game = this.game;
    if (game && s.conn.kind === 'player') {
      const id = s.conn.id;
      const stillConnected = [...this.sessions.values()].some((x) => x.conn.kind === 'player' && x.conn.id === id);
      if (!stillConnected) {
        const before = game.phase;
        game.setOnline(id, false);
        this.broadcastRoster();
        if (game.phase !== before) this.afterPhaseChange();
      }
    }
    if (this.sessions.size === 0) this.stopTimer();
  }

  // ---------- broadcasting ----------

  private afterPhaseChange(): void {
    const game = this.game!;
    this.broadcast({ t: 'phase', phase: game.phaseInfo() });
    for (const [ws, s] of this.sessions) {
      if (s.conn.kind !== 'player') continue;
      const p = game.players.get(s.conn.id);
      if (!p) continue;
      this.send(ws, { t: 'you', you: game.you(p) });
      if (game.phase === 'PLAYING') this.send(ws, { t: 'teleport', floor: p.floor, x: p.x, y: p.y });
    }
    if (game.phase === 'ENDED') this.broadcast({ t: 'ended', ranking: game.ranking() });
    this.broadcastRoster();
    void this.persist();
  }

  private broadcastRoster(): void {
    if (this.game) this.broadcast({ t: 'roster', players: this.game.roster() });
  }

  private broadcastSnapshots(game: Game): void {
    if (game.phase === 'ENDED') return;
    const cache = new Map<FloorId, string>();
    for (const [ws, s] of this.sessions) {
      if (s.conn.kind !== 'player') continue;
      const p = game.players.get(s.conn.id);
      if (!p) continue;
      const floor = game.viewFloor(p);
      let payload = cache.get(floor);
      if (!payload) {
        const msg: ServerMsg = { t: 'snapshot', players: game.snapshotFor(floor) };
        payload = JSON.stringify(msg);
        cache.set(floor, payload);
      }
      this.sendRaw(ws, payload);
    }
  }

  private broadcast(msg: ServerMsg): void {
    const payload = JSON.stringify(msg);
    for (const [ws, s] of this.sessions) if (s.conn.kind !== 'pending') this.sendRaw(ws, payload);
  }

  private send(ws: WebSocket, msg: ServerMsg): void {
    this.sendRaw(ws, JSON.stringify(msg));
  }

  private sendRaw(ws: WebSocket, payload: string): void {
    try {
      ws.send(payload);
    } catch {
      // socket already closing; the close handler cleans up
    }
  }

  // ---------- timer & storage ----------

  private ensureTimer(): void {
    if (!this.timer) this.timer = setInterval(() => this.onTick(), TICK_MS);
  }

  private stopTimer(): void {
    if (this.timer) clearInterval(this.timer);
    this.timer = null;
  }

  private onTick(): void {
    const game = this.game;
    if (!game || this.sessions.size === 0) {
      this.stopTimer();
      return;
    }
    if (game.tick()) this.afterPhaseChange();
    this.broadcastSnapshots(game);
  }

  private async persist(): Promise<void> {
    if (this.game) await this.ctx.storage.put('game', this.game.toData());
  }
}
```

```ts
import { DEFAULT_TIME_LIMIT_MIN, MAX_TIME_LIMIT_MIN, MIN_TIME_LIMIT_MIN } from '../../shared/src/constants';
import type { Env } from './env';
import { GameRoom } from './GameRoom';

export { GameRoom };

function corsHeaders(env: Env): Record<string, string> {
  return {
    'Access-Control-Allow-Origin': env.ALLOWED_ORIGIN || '*',
    'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
    'Access-Control-Allow-Headers': 'content-type',
  };
}

function json(env: Env, body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { 'content-type': 'application/json', ...corsHeaders(env) },
  });
}

function safeEqual(a: string, b: string): boolean {
  const ea = new TextEncoder().encode(a);
  const eb = new TextEncoder().encode(b);
  let diff = ea.length ^ eb.length;
  for (let i = 0; i < Math.max(ea.length, eb.length); i++) diff |= (ea[i] ?? 0) ^ (eb[i] ?? 0);
  return diff === 0;
}

function randomPin(): string {
  return String((crypto.getRandomValues(new Uint32Array(1))[0] % 900_000) + 100_000);
}

function room(env: Env, pin: string) {
  return env.GAME_ROOM.get(env.GAME_ROOM.idFromName(pin));
}

async function createGame(req: Request, env: Env): Promise<Response> {
  let body: { password?: unknown; timeLimitMin?: unknown };
  try {
    body = await req.json();
  } catch {
    return json(env, { error: 'BAD_REQUEST' }, 400);
  }
  if (!env.HOST_PASSWORD || typeof body.password !== 'string' || !safeEqual(body.password, env.HOST_PASSWORD)) {
    return json(env, { error: 'BAD_PASSWORD' }, 403);
  }
  const requested = Number(body.timeLimitMin);
  const timeLimitMin = Number.isFinite(requested)
    ? Math.min(MAX_TIME_LIMIT_MIN, Math.max(MIN_TIME_LIMIT_MIN, Math.round(requested)))
    : DEFAULT_TIME_LIMIT_MIN;
  const hostToken = crypto.randomUUID();
  for (let attempt = 0; attempt < 10; attempt++) {
    const pin = randomPin();
    if (await room(env, pin).init({ pin, timeLimitMin, hostToken })) return json(env, { pin, hostToken, timeLimitMin });
  }
  return json(env, { error: 'BUSY' }, 503);
}

export default {
  async fetch(req: Request, env: Env): Promise<Response> {
    const url = new URL(req.url);
    if (req.method === 'OPTIONS') return new Response(null, { status: 204, headers: corsHeaders(env) });
    if (url.pathname === '/') return new Response('Key House server OK', { headers: corsHeaders(env) });
    if (url.pathname === '/api/create' && req.method === 'POST') return createGame(req, env);

    const info = url.pathname.match(/^\/api\/game\/(\d{6})$/);
    if (info && req.method === 'GET') return json(env, await room(env, info[1]).info());

    const ws = url.pathname.match(/^\/ws\/(\d{6})$/);
    if (ws) {
      if (req.headers.get('Upgrade') !== 'websocket') return new Response('Expected WebSocket', { status: 426 });
      return room(env, ws[1]).fetch(req);
    }
    return new Response('Not found', { status: 404, headers: corsHeaders(env) });
  },
} satisfies ExportedHandler<Env>;
```

```js
class Client {
  constructor(pin) {
    this.inbox = [];
    this.waiters = [];
    this.ws = new WebSocket(`${WS_BASE}/ws/${pin}`);
    this.opened = new Promise((resolve, reject) => {
      this.ws.onopen = resolve;
      this.ws.onerror = reject;
    });
    this.ws.onmessage = (e) => {
      const m = JSON.parse(e.data);
      const w = this.waiters.find((x) => x.pred(m));
      if (w) {
        this.waiters.splice(this.waiters.indexOf(w), 1);
        w.resolve(m);
      } else this.inbox.push(m);
    };
  }
  send(m) {
    this.ws.send(JSON.stringify(m));
  }
  wait(pred, timeout = 6000) {
    const i = this.inbox.findIndex(pred);
    if (i >= 0) return Promise.resolve(this.inbox.splice(i, 1)[0]);

      const timer = setTimeout(() => reject(new Error('timeout waiting for message')), timeout);
      this.waiters.push({ pred, resolve: (m) => { clearTimeout(timer); resolve(m); } });
    });
  }
  close() {
    this.ws.close();
  }

await sleep(200);
```

```ts
        expect(placeholders(DICTS[l][key]), `${l}:${key}`).toEqual(placeholders(DICTS.kk[key]));
```

```ts
const STORE_KEY = 'kh.lang';
const listeners = new Set<() => void>();

function detect(): Lang {
  try {
    const saved = localStorage.getItem(STORE_KEY);
    if (saved && (LANGS as readonly string[]).includes(saved)) return saved as Lang;
  } catch {
    // no storage (tests, privacy mode)
  }
  return 'kk';
}

let current: Lang = detect();

export function getLang(): Lang {
  return current;
}

export function setLang(lang: Lang): void {
  current = lang;
  try {
    localStorage.setItem(STORE_KEY, lang);
  } catch {
    // ignore
  }
  if (typeof document !== 'undefined') document.documentElement.lang = lang;
  listeners.forEach((fn) => fn());
}

export function onLangChange(fn: () => void): () => void {
  listeners.add(fn);
  return () => listeners.delete(fn);
}

export function t(key: string, params?: Record<string, string | number>): string {
  const s = DICTS[current][key] ?? DICTS.kk[key] ?? key;
  return s.replace(/\{(\w+)\}/g, (_, k: string) => (params && k in params ? String(params[k]) : `{${k}}`));
}
```

```ts
function tone(freq: number, dur: number, type: OscillatorType = 'square', vol = 0.06, delay = 0, slideTo?: number): void {

  unlockAudio();
  if (!ctx) return;
  const t0 = ctx.currentTime + delay;
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  osc.type = type;
  osc.frequency.setValueAtTime(freq, t0);
  if (slideTo) osc.frequency.exponentialRampToValueAtTime(slideTo, t0 + dur);
  gain.gain.setValueAtTime(vol, t0);
  gain.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
  osc.connect(gain).connect(ctx.destination);
  osc.start(t0);
  osc.stop(t0 + dur + 0.02);
```

```ts
export type ConnStatus = 'connecting' | 'open' | 'reconnecting' | 'failed';

export interface WebSocketLike {
  readyState: number;
  send(data: string): void;
  close(): void;
  onopen: ((ev: never) => void) | null;
  onmessage: ((ev: { data: unknown }) => void) | null;
  onclose: ((ev: { code: number }) => void) | null;
}
export type WebSocketCtor = new (url: string) => WebSocketLike;

export interface ConnectionOptions {
  url: string;
  hello: () => ClientMsg | null;
  onMessage: (msg: ServerMsg) => void;
  onStatus: (s: ConnStatus) => void;
  WebSocketImpl?: WebSocketCtor;
  maxRetries?: number;
  baseDelayMs?: number;
}

const OPEN = 1;

export class Connection {
  private ws: WebSocketLike | null = null;
  private retries = 0;
  private closedByUser = false;
  private timer: ReturnType<typeof setTimeout> | null = null;

  constructor(private readonly o: ConnectionOptions) {}

  open(): void {
    this.closedByUser = false;
    this.retries = 0;
    this.connect();
  }

  send(msg: ClientMsg): void {
    if (this.ws && this.ws.readyState === OPEN) this.ws.send(JSON.stringify(msg));
  }

  close(): void {
    this.closedByUser = true;
    if (this.timer) clearTimeout(this.timer);
    this.timer = null;
    const ws = this.ws;
    this.ws = null;
    ws?.close();
  }

  private connect(): void {
    const Impl = this.o.WebSocketImpl ?? (WebSocket as unknown as WebSocketCtor);
    this.o.onStatus(this.retries === 0 ? 'connecting' : 'reconnecting');
    const ws = new Impl(this.o.url);
    this.ws = ws;
    ws.onopen = () => {
      this.retries = 0;
      this.o.onStatus('open');
      const hello = this.o.hello();
      if (hello) ws.send(JSON.stringify(hello));
    };
    ws.onmessage = (ev) => {
      let msg: ServerMsg;
      try {
        msg = JSON.parse(String(ev.data));
      } catch {
        return;
      }
      this.o.onMessage(msg);
    };
    ws.onclose = (ev) => {
      if (this.ws !== ws) return;
      this.ws = null;
      if (this.closedByUser) return;
      if (ev.code >= 4000) {
        this.o.onStatus('failed');
        return;
      }
      this.scheduleReconnect();
    };
  }

  private scheduleReconnect(): void {
    const max = this.o.maxRetries ?? 5;
    if (this.retries >= max) {
      this.o.onStatus('failed');
      return;
    }
    const delay = (this.o.baseDelayMs ?? 500) * 2 ** this.retries;
    this.retries++;
    this.o.onStatus('reconnecting');
    this.timer = setTimeout(() => this.connect(), delay);
  }
}
```

```ts
import type { Dir } from '../../../shared/src/protocol';

export const CHAR_W = 16;
export const CHAR_H = 24;
/** Row order inside a character sheet. */
export const DIRS: Dir[] = ['down', 'left', 'right', 'up'];

export type Accessory = 'none' | 'takiya' | 'borik' | 'glasses' | 'scarf' | 'cap';
export interface CharacterLook {
  skin: string;
  hair: string;
  hairStyle: number;
  shirt: string;
  pants: string;
  accessory: Accessory;
}

const SKINS = ['#f5d0b0', '#e8b48f', '#c98e64', '#a56a43', '#7a4a2c'];
const HAIRS = ['#2b1d14', '#5a3a22', '#a0632e', '#d9b35f', '#1a1a1a'];
const SHIRTS = ['#d94f4f', '#3b7dd8', '#3fa96b', '#e0a526', '#8a55c9', '#e06aa8', '#2fb3b3', '#f07f3c'];
const PANTS = ['#2f3a56', '#4a3b2f', '#3d4a3a', '#555b66'];
const ACCESSORIES: Accessory[] = ['none', 'takiya', 'borik', 'glasses', 'scarf', 'cap'];

export function characterLook(i: number): CharacterLook {
  return {
    skin: SKINS[i % 5],
    hairStyle: Math.floor(i / 5) % 5,
    hair: HAIRS[(i * 2 + 1) % 5],
    shirt: SHIRTS[(i * 3) % SHIRTS.length],
    pants: PANTS[(i + Math.floor(i / 5)) % PANTS.length],
    accessory: ACCESSORIES[(i * 7 + 3) % ACCESSORIES.length],
  };
}

export function charKey(i: number): string {
  return `char${i}`;
}

type Px = (x: number, y: number, w: number, h: number, c: string) => void;

function shade(hex: string, k = 0.75): string {
  const n = parseInt(hex.slice(1), 16);
  return `rgb(${Math.round((n >> 16) * k)},${Math.round(((n >> 8) & 255) * k)},${Math.round((n & 255) * k)})`;
}

function drawHair(px: Px, look: CharacterLook, dir: Dir): void {
  if (look.accessory === 'scarf') return; // the орамал covers the hair
  const h = look.hair;
  if (dir === 'up') {
    px(4, 2, 8, 8, h);
    if (look.hairStyle === 1 || look.hairStyle === 4) px(4, 10, 8, 2, h);
    if (look.hairStyle === 3) px(6, 0, 4, 2, h);
    return;
  }
  const side = dir !== 'down';
  switch (look.hairStyle) {
    case 0: // short
      px(4, 2, 8, 3, h);
      if (side) px(8, 5, 4, 3, h);
      else { px(4, 5, 1, 2, h); px(11, 5, 1, 2, h); }
      break;
    case 1: // long
      px(4, 2, 8, 3, h);
      if (side) px(8, 5, 4, 7, h);
      else { px(3, 4, 1, 8, h); px(12, 4, 1, 8, h); }
      break;
    case 2: // spiky
      px(4, 2, 8, 2, h);
      px(5, 1, 1, 1, h);
      px(7, 0, 2, 2, h);
      px(10, 1, 1, 1, h);
      if (side) px(9, 4, 3, 3, h);
      break;
    case 3: // bun
      px(4, 2, 8, 3, h);
      px(6, 0, 4, 2, h);
      if (side) px(9, 5, 3, 3, h);
      break;
    default: // bob
      px(3, 2, 10, 3, h);
      if (side) px(8, 5, 5, 5, h);
      else { px(3, 5, 2, 5, h); px(11, 5, 2, 5, h); }
  }
}

function drawAccessory(px: Px, look: CharacterLook, dir: Dir): void {
  switch (look.accessory) {
    case 'takiya':
      px(4, 1, 8, 2, '#7a1f2b');
      px(5, 1, 1, 1, '#e8c547');
      px(8, 1, 1, 1, '#e8c547');
      px(10, 1, 1, 1, '#e8c547');

    case 'borik':
      px(3, 1, 10, 3, '#6b4a2b');
      px(5, 0, 6, 1, '#b8322e');
      break;
    case 'glasses':
      if (dir === 'down') { px(5, 7, 3, 1, '#111111'); px(8, 7, 3, 1, '#111111'); }
      else if (dir !== 'up') px(4, 7, 3, 1, '#111111');
      break;
    case 'scarf': {
      const c = '#f0eadc', d = '#c9493f';
      px(3, 2, 10, 3, c);
      px(5, 3, 1, 1, d);
      px(8, 3, 1, 1, d);
      px(11, 3, 1, 1, d);
      if (dir === 'up') px(3, 5, 10, 7, c);
      else if (dir === 'down') { px(3, 5, 1, 6, c); px(12, 5, 1, 6, c); }
      else px(8, 5, 5, 6, c);
      break;
    }
    case 'cap':
      px(4, 1, 8, 3, '#2255aa');
      if (dir === 'down') px(4, 4, 8, 1, '#173d7a');
      else if (dir !== 'up') px(1, 3, 4, 1, '#173d7a');
      break;
    default:
      break;
  }
}

/** Draws one 16×24 frame. frame 0 = standing, 1 = left foot forward, 2 = right foot forward. */
export function drawCharacter(g: CanvasRenderingContext2D, look: CharacterLook, dir: Dir, frame: number, ox: number, oy: number): void {
  const mirror = dir === 'right';
  const side = dir === 'left' || dir === 'right';
  const px: Px = (x, y, w, h, c) => {
    g.fillStyle = c;
    g.fillRect(ox + (mirror ? CHAR_W - x - w : x), oy + y, w, h);
  };
  const shoe = '#2a2a2a';
  const lUp = frame === 1 ? 1 : 0;
  const rUp = frame === 2 ? 1 : 0;

  px(3, 22, 10, 2, 'rgba(0,0,0,0.28)');
  if (side) {
    px(5, 17, 3, 4 - rUp, shade(look.pants));
    px(5, 21 - rUp, 3, 1, shoe);
    px(8, 17, 3, 4 - lUp, look.pants);
    px(8, 21 - lUp, 3, 1, shoe);
  } else {
    px(5, 17, 2, 4 - lUp, look.pants);
    px(5, 21 - lUp, 2, 1, shoe);
    px(9, 17, 2, 4 - rUp, look.pants);
    px(9, 21 - rUp, 2, 1, shoe);
  }
  px(4, 11, 8, 6, look.shirt);
  px(4, 16, 8, 1, look.pants);
  if (side) {
    const swing = frame === 1 ? -1 : frame === 2 ? 1 : 0;
    px(7 + swing, 12, 2, 4, shade(look.shirt));
    px(7 + swing, 16, 2, 1, look.skin);
  } else {
    px(3, 12, 1, 4, look.shirt);
    px(12, 12, 1, 4, look.shirt);
    px(3, 16, 1, 1, look.skin);
    px(12, 16, 1, 1, look.skin);
  }
  px(4, 3, 8, 8, look.skin);
  if (dir === 'down') {
    px(6, 7, 1, 2, '#1d1d1d');
    px(9, 7, 1, 2, '#1d1d1d');
    px(7, 9, 2, 1, '#c0605a');
  } else if (side) {
    px(5, 7, 1, 2, '#1d1d1d');
  }
  drawHair(px, look, dir);
  drawAccessory(px, look, dir);
}

export function buildCharacterSheet(look: CharacterLook): HTMLCanvasElement {
  const c = document.createElement('canvas');
  c.width = CHAR_W * 3;
  c.height = CHAR_H * DIRS.length;
  const g = c.getContext('2d')!;
  DIRS.forEach((dir, row) => {
    for (let f = 0; f < 3; f++) drawCharacter(g, look, dir, f, f * CHAR_W, row * CHAR_H);
  });
  return c;
}

export function characterPreview(i: number): HTMLCanvasElement {
  const c = document.createElement('canvas');
  c.width = CHAR_W;
  c.height = CHAR_H;
  c.className = 'pix';
  drawCharacter(c.getContext('2d')!, characterLook(i), 'down', 0, 0, 0);
  return c;
}
```

```ts
function paintTile(g: CanvasRenderingContext2D, map: GameMap, tx: number, ty: number): void {
```

```ts
import { SPEED, TILE } from '../../../shared/src/constants';
import { moveAllowed, type GameMap, type Point, type RoomId } from '../../../shared/src/map';
import type { Dir } from '../../../shared/src/protocol';

const MAX_DT_MS = 100;
const DEADZONE = 0.05;

export function stepMovement(map: GameMap, pos: Point, vec: Point, dtMs: number, answered: ReadonlySet<RoomId>): Point {
  const len = Math.hypot(vec.x, vec.y);
  if (len < DEADZONE) return pos;
  const k = Math.min(len, 1) / len;
  const dist = (SPEED * Math.min(dtMs, MAX_DT_MS)) / 1000;
  let p = tryAxis(map, pos, vec.x * k * dist, 'x', answered);
  p = tryAxis(map, p, vec.y * k * dist, 'y', answered);
  return p;
}

function tryAxis(map: GameMap, p: Point, d: number, axis: 'x' | 'y', answered: ReadonlySet<RoomId>): Point {
  if (d === 0) return p;
  const next = axis === 'x' ? { x: p.x + d, y: p.y } : { x: p.x, y: p.y + d };
  if (moveAllowed(map, p, next, answered)) return next;
  // Corner assist: when blocked, slide toward the centre of the current tile on the other axis
  // so doors one tile wide are easy to walk through.
  const other = axis === 'x' ? 'y' : 'x';
  const centre = (Math.floor(p[other] / TILE) + 0.5) * TILE;
  const off = centre - p[other];
  if (Math.abs(off) < 0.5) return p;
  // Only assist when the path is open from the tile centre (a door), not against a solid wall.
  const aligned = other === 'x' ? { x: centre, y: p.y } : { x: p.x, y: centre };
  const beyond = axis === 'x' ? { x: aligned.x + d, y: aligned.y } : { x: aligned.x, y: aligned.y + d };
  if (!moveAllowed(map, aligned, beyond, answered)) return p;
  const step = Math.sign(off) * Math.min(Math.abs(off), Math.abs(d));
  const nudged = other === 'x' ? { x: p.x + step, y: p.y } : { x: p.x, y: p.y + step };
  return moveAllowed(map, p, nudged, answered) ? nudged : p;
}

export function dirFromVec(vec: Point, prev: Dir): Dir {
  if (Math.abs(vec.x) < DEADZONE && Math.abs(vec.y) < DEADZONE) return prev;
  if (Math.abs(vec.x) > Math.abs(vec.y)) return vec.x < 0 ? 'left' : 'right';
  return vec.y < 0 ? 'up' : 'down';
}
```

```ts
import type { Point } from '../../../shared/src/map';

interface Sample { t: number; x: number; y: number }

/** Buffers timestamped positions of a remote player and samples them slightly in the past. */
export class Interp {
  private buf: Sample[] = [];

  push(t: number, x: number, y: number): void {
    this.buf.push({ t, x, y });
    if (this.buf.length > 20) this.buf.shift();
  }

  reset(): void {
    this.buf = [];
  }

  last(): Point | null {
    const s = this.buf[this.buf.length - 1];
    return s ? { x: s.x, y: s.y } : null;
  }

  sample(t: number): Point | null {
    const b = this.buf;
    if (b.length === 0) return null;
    if (t <= b[0].t) return { x: b[0].x, y: b[0].y };
    for (let i = b.length - 1; i >= 0; i--) {
      if (b[i].t > t) continue;
      const a = b[i];
      const n = b[i + 1];
      if (!n) return { x: a.x, y: a.y };
      const k = (t - a.t) / (n.t - a.t);
      return { x: a.x + (n.x - a.x) * k, y: a.y + (n.y - a.y) * k };
    }
    return null;
  }
}
```

```ts
    this.label.setVisible(v);
  }

    this.sprite.destroy();
```

```ts
    if (!key) return null;
    this.keySprites.delete(roomId);
    this.overlay = this.overlay.filter((o) => o !== key);
    this.tweens.killTweensOf(key);
    return key;
  }

  // ---------- frame loop ----------

  update(_time: number, delta: number): void {
    const now = performance.now();
    const renderT = now - INTERP_DELAY_MS;
    for (const o of this.others.values()) {
      const s = o.interp.sample(renderT);
      if (s) o.avatar.setPos(s.x, s.y);
    }
    if (!this.me || !this.you || this.spectateId || this.viewFloor !== this.localFloor) return;

    const map = MAPS[this.localFloor];
    const answered = new Set(Object.keys(this.you.answered) as RoomId[]);
    let vec = { x: 0, y: 0 };
    if (!this.frozen) {
      const k = this.keys;
      vec.x = (k.D.isDown || k.RIGHT.isDown ? 1 : 0) - (k.A.isDown || k.LEFT.isDown ? 1 : 0);
      vec.y = (k.S.isDown || k.DOWN.isDown ? 1 : 0) - (k.W.isDown || k.UP.isDown ? 1 : 0);
      if (vec.x === 0 && vec.y === 0) vec = { ...this.touchVec };
    }
    const next = stepMovement(map, this.pos, vec, delta, answered);
    const moving = next.x !== this.pos.x || next.y !== this.pos.y;
    if (moving || moving !== this.moving) this.dirty = true;
    if (moving && now - this.lastStepSound > STEP_SOUND_MS) {
      sfx.step();
      this.lastStepSound = now;
    }
    this.dir = dirFromVec(vec, this.dir);
    this.pos = next;
    this.moving = moving;
    this.me.setPos(next.x, next.y);
    this.me.anim(this.dir, moving);
    if (this.dirty && now - this.lastSend >= SEND_MS) this.flushMove(now);

    this.checkStairs();
    this.checkPrompt();
    const pressed = Phaser.Input.Keyboard.JustDown(this.keys.E) || this.actionQueued;
    this.actionQueued = false;
    if (pressed && !this.frozen && this.promptRoom) this.cb?.onInteract(this.promptRoom);
  }

  private flushMove(now = performance.now()): void {
    this.cb?.onMove(Math.round(this.pos.x * 10) / 10, Math.round(this.pos.y * 10) / 10, this.dir, this.moving);
    this.lastSend = now;
    this.dirty = false;
  }

  private checkStairs(): void {
    const on = onStairs(MAPS[this.localFloor], this.pos.x, this.pos.y);
    if (on && !this.stairsLatch) {
      this.stairsLatch = true;
      const locked = this.localFloor === 'f1' && !this.you?.floor2Unlocked;
      if (!locked && this.you?.status === 'playing') {
        this.flushMove();
        this.cb?.onStairs();
      }
    } else if (!on) {
      this.stairsLatch = false;
    }
  }

  private checkPrompt(): void {
    const map = MAPS[this.localFloor];
    let room: RoomId | null = null;
    if (this.you?.status === 'playing') {
      for (const r of map.rooms) {
        if (!this.you.answered[r.id] && nearPedestal(r, this.pos.x, this.pos.y)) {
          room = r.id;
          break;
        }
      }
    }
    const locked = this.localFloor === 'f1' && !this.you?.floor2Unlocked && onStairs(map, this.pos.x, this.pos.y);
    const prompt: Prompt = room ? 'interact' : locked ? 'stairsLocked' : null;
    this.promptRoom = room;
    if (prompt !== this.prompt) {
      this.prompt = prompt;
      this.cb?.onPrompt(prompt);
    }
  }

  // ---------- floor rendering ----------

  private showFloor(floor: FloorId): void {
    if (this.viewFloor !== floor) {
      this.viewFloor = floor;
      this.mapImage?.destroy();
      const map = MAPS[floor];
      this.mapImage = this.add.image(0, 0, ensureMapTexture(this, floor)).setOrigin(0, 0).setDepth(-10_000);
      this.cameras.main.setBounds(0, 0, map.width * TILE, map.height * TILE);
      for (const o of this.others.values()) o.avatar.destroy();
      this.others.clear();
    }
    this.rebuildOverlay();
    this.syncMeVisibility();
    this.follow();
  }

  private syncMeVisibility(): void {
    this.me?.setVisible(!this.spectateId && this.viewFloor === this.localFloor);
  }

  private follow(): void {
    const cam = this.cameras.main;
    const target = this.spectateId ? this.others.get(this.spectateId)?.avatar.sprite : this.me?.sprite;
    if (target) cam.startFollow(target, true, 0.15, 0.15, 0, 24);
    else cam.stopFollow();
  }

  private applyZoom(): void {
    const m = Math.min(this.scale.width, this.scale.height);
    this.cameras.main.setZoom(m < 500 ? 1.25 : m < 800 ? 2 : m < 1100 ? 2.5 : 3);
  }

  private rebuildOverlay(): void {
    for (const o of this.overlay) o.destroy();
    this.overlay = [];
    this.keySprites.clear();
    this.chain?.destroy();
    this.chain = null;
    this.board = null;
    const floor = this.viewFloor;
    if (!floor) return;
    const map = MAPS[floor];
    const you = this.you;
    const showMine = !!you && you.status === 'playing' && you.floor === floor && !this.spectateId;

    for (const room of map.rooms) {
      const label = this.add
        .text((room.rect.x + room.rect.w / 2) * TILE, room.rect.y * TILE + 4, t(`room.${room.id}`), {
          ...TEXT_STYLE,
          fontSize: '11px',
          color: '#ffffff',
          backgroundColor: '#00000066',
          padding: { x: 4, y: 1 },
        })
        .setOrigin(0.5, 0)
        .setDepth(25_000);
      this.overlay.push(label);
      if (!showMine) continue;
      const mark = you!.answered[room.id];
      if (mark) {
        const d = tileCenter(room.door.x, room.door.y);
        this.overlay.push(this.add.image(d.x, d.y, mark === 'correct' ? 'mark-correct' : 'mark-wrong').setScale(1.5).setDepth(25_000));
        continue;
      }
      const p = tileCenter(room.pedestal.x, room.pedestal.y);
      const key = this.add.image(p.x, p.y - 14, 'key').setScale(1.5).setDepth(p.y + 1);
      key.preFX?.addGlow(0xffe066, 4, 0, false, 0.1, 10);
      this.tweens.add({ targets: key, y: key.y - 5, duration: 900, yoyo: true, repeat: -1, ease: 'Sine.easeInOut' });
      this.keySprites.set(room.id, key);
      this.overlay.push(key);
    }

    if (floor === 'f1' && map.stairs && !you?.floor2Unlocked) {
      const s = map.stairs;
      this.chain = this.add.image((s.x + s.w / 2) * TILE, (s.y + s.h / 2) * TILE, 'chain').setDepth(24_000);
    }

    if (floor === 'lobby') {
      this.board = this.add
        .text(12 * TILE, TILE + 6, '', { ...TEXT_STYLE, fontSize: '12px', color: '#7cffb2', align: 'center', lineSpacing: 1 })
        .setOrigin(0.5, 0)
        .setDepth(25_000);
      this.overlay.push(this.board);
      this.refreshBoard();
    }
  }

  private refreshBoard(): void {
    if (!this.board) return;
    const top = rank([...this.roster.values()]).slice(0, 5);
    const lines = top.map((p) => `${p.place}. ${p.name}  🔑${p.keys}  🚪${p.rooms}`);
    this.board.setText([t('board.title'), ...lines].join('\n'));
  }
}
```

```ts
/** Shows 3-2-1-Go using the server's countdown end time. Returns a cancel function. */
export function runCountdown(root: HTMLElement, endsAtServer: number, offset: number, onDone: () => void): () => void {
  root.hidden = false;
  let shown = '';
  const finish = () => {
    clearInterval(id);
    root.hidden = true;
    root.innerHTML = '';
  };
  const tick = () => {
    const ms = endsAtServer - (Date.now() + offset);
    const label = ms > 0 ? String(Math.ceil(ms / 1000)) : t('countdown.go');
    if (label !== shown) {
      shown = label;
      root.innerHTML = `<div class="cd-num">${escapeHtml(label)}</div>`;
      if (ms > 0) sfx.beep();
      else sfx.go();
    }
    if (ms <= -800) {
      finish();
      onDone();
    }
  };
  const id = window.setInterval(tick, 100);
  tick();
  return finish;
}
```

```ts
export function isTouchDevice(): boolean {
  return matchMedia('(pointer: coarse)').matches || 'ontouchstart' in window;
}

const RADIUS = 50;

export class TouchControls {
  private readonly act: HTMLButtonElement;
  private pointerId: number | null = null;

  constructor(root: HTMLElement, onVector: (v: { x: number; y: number }) => void, onAction: () => void) {
    root.innerHTML = `<div class="joy"><div class="knob"></div></div><button class="act" type="button" aria-label="action">✋</button>`;
    root.hidden = false;
    const joy = root.querySelector<HTMLElement>('.joy')!;
    const knob = root.querySelector<HTMLElement>('.knob')!;
    this.act = root.querySelector<HTMLButtonElement>('.act')!;

    const update = (e: PointerEvent) => {
      const r = joy.getBoundingClientRect();
      let dx = e.clientX - (r.left + r.width / 2);
      let dy = e.clientY - (r.top + r.height / 2);
      const len = Math.hypot(dx, dy);
      if (len > RADIUS) {
        dx = (dx / len) * RADIUS;
        dy = (dy / len) * RADIUS;
      }
      knob.style.transform = `translate(${dx}px, ${dy}px)`;
      onVector({ x: dx / RADIUS, y: dy / RADIUS });
    };
    const reset = () => {
      this.pointerId = null;
      knob.style.transform = '';
      onVector({ x: 0, y: 0 });
    };
    joy.addEventListener('pointerdown', (e) => {
      this.pointerId = e.pointerId;
      joy.setPointerCapture(e.pointerId);
      update(e);
    });
    joy.addEventListener('pointermove', (e) => {
      if (e.pointerId === this.pointerId) update(e);
    });
    joy.addEventListener('pointerup', reset);
    joy.addEventListener('pointercancel', reset);
    this.act.addEventListener('pointerdown', (e) => {
      e.preventDefault();
      onAction();
    });
  }

  setReady(on: boolean): void {
    this.act.classList.toggle('ready', on);
  }
}
```

```ts
    this.root.querySelector('.watch')?.addEventListener('click', () => this.cycle(1));
    this.root.querySelector('.back')?.addEventListener('click', () => this.choose(null));
  }

  private cycle(step: number): void {
    const n = this.targets.length;
    if (!n) return;
    const i = this.targets.findIndex((p) => p.id === this.current);
    const base = i < 0 ? (step > 0 ? -1 : 0) : i;
    this.choose(this.targets[(base + step + n) % n].id);
  }

  private choose(id: string | null): void {
    this.current = id;
    this.onChange(id);
    this.render();
  }
}
```

```ts
  forget();
  s.roster = [];
  s.ranking = null;
  s.phase = null;
  s.error = '';
  overlay.hidden = true;
  renderLogin();
}

function renderDash(): void {
  s.view = 'dash';
  const ph = s.phase?.phase ?? 'LOBBY';
  const joinUrl = `${location.origin}/?pin=${s.pin}`;
  root.innerHTML = `
    <div class="host">
      <header class="host-head">
        <div>
          <div class="label">${t('host.pinLabel')}</div>
          <div class="pin">${s.pin}</div>
          <div class="label">${t('host.joinAt', { url: escapeHtml(joinUrl) })}</div>
        </div>
        <div class="stack" style="justify-items:end">
          <div class="label"><span>${t(`host.phase.${ph}`)}</span> · <span id="count"></span></div>
          <div class="timer" id="timer"></div>
          <div class="row">
            ${ph === 'LOBBY' ? `<button class="btn btn-go" id="start" type="button">${t('host.start')}</button>` : ''}
            ${ph === 'PLAYING' || ph === 'COUNTDOWN' ? `<button class="btn btn-danger" id="stop" type="button">${t('host.stop')}</button>` : ''}
            ${ph === 'ENDED' ? `<button class="btn btn-gold" id="new" type="button">${t('host.newGame')}</button>` : ''}
          </div>
        </div>
      </header>
      <section id="podium"></section>
      <table class="table">

        </tr></thead>
        <tbody id="rows"></tbody>
      </table>
    </div>`;
  root.querySelector('#start')?.addEventListener('click', () => s.conn?.send({ t: 'start' }));
  root.querySelector('#stop')?.addEventListener('click', () => {
    if (confirm(t('host.confirmStop'))) s.conn?.send({ t: 'stop' });
  });
  root.querySelector('#new')?.addEventListener('click', newGame);
  if (ph === 'ENDED' && s.ranking) byId('podium').append(podium(s.ranking));
  renderRows();
  renderCount();
  renderTimer();
}

function renderCount(): void {
  const c = root.querySelector('#count');
  if (c) c.textContent = `👥 ${s.roster.length}`;
  const start = root.querySelector<HTMLButtonElement>('#start');
  if (start) start.disabled = s.roster.length === 0;
}

function renderRows(): void {
  const body = root.querySelector('#rows');
  if (!body) return;
  const lobby = (s.phase?.phase ?? 'LOBBY') === 'LOBBY';
  body.innerHTML = '';
  for (const p of rank(s.roster)) {
    const tr = document.createElement('tr');
    if (!p.online) tr.className = 'off';
    tr.innerHTML = `
      <td>${lobby ? '' : p.place}</td><td class="c"></td><td>${escapeHtml(p.name)}</td>
      <td>${p.rooms}</td><td>${p.keys}</td><td>${t(`floor.${p.floor}`)}</td>
      <td>${p.online ? t(`status.${p.status}`) : t('status.offline')}</td><td>${fmtTime(p.lastKeyAt)}</td>`;
    tr.querySelector('.c')!.append(characterPreview(p.character));
    body.append(tr);
  }
}

function renderTimer(): void {
  const el = root.querySelector('#timer');
  if (!el) return;
  const p = s.phase;
  el.textContent =
    p?.phase === 'PLAYING' && p.endsAt ? `⏱ ${fmtTime(Math.max(0, Math.ceil((p.endsAt - (Date.now() + s.offset)) / 1000)))}` : '';
}

mountTopBar(byId('topbar'), false);
onLangChange(() => {
  if (s.view === 'dash') renderDash();
  else if (s.view === 'login') renderLogin();
});
setInterval(renderTimer, 250);

const saved = loadSaved();
if (saved) {
  s.pin = saved.pin;
  s.hostToken = saved.hostToken;
  connect();
} else {
  renderLogin();
}
```

```ts
import { expect, test, type BrowserContext, type Page } from '@playwright/test';

const PASSWORD = process.env.HOST_PASSWORD ?? 'dev-password';

function watchErrors(page: Page, sink: string[]): void {
  page.on('pageerror', (e) => sink.push(e.message));
}

async function hostCreates(page: Page): Promise<string> {
  await page.goto('/host.html');
  await page.locator('#pw').fill(PASSWORD);
  await page.locator('#tl').fill('5');
  await page.locator('form button[type=submit]').click();
  const pinEl = page.locator('.pin');
  await expect(pinEl).toHaveText(/^\d{6}$/);
  return (await pinEl.textContent())!.trim();
}

async function startJoin(ctx: BrowserContext, pin: string, name: string, char: number, errors: string[]): Promise<Page> {
  const page = await ctx.newPage();
  watchErrors(page, errors);
  await page.goto(`/?pin=${pin}`);
  await page.locator('form button[type=submit]').click();
  await page.locator('#name').fill(name);
  await page.locator('form button[type=submit]').click();
  await page.locator('.char').nth(char).click();
  await page.locator('#join').click();
  return page;
}

async function join(ctx: BrowserContext, pin: string, name: string, char: number, errors: string[]): Promise<Page> {
  const page = await startJoin(ctx, pin, name, char, errors);
  await expect(page.locator('#lobbybar')).toBeVisible();
  return page;
}

test('full round: join, start, play, reload, stop, results', async ({ page, context }) => {
  const errors: string[] = [];
  watchErrors(page, errors);
  const pin = await hostCreates(page);

  const p1 = await join(context, pin, 'Аян', 0, errors);
  const p2 = await join(context, pin, 'Bota', 5, errors);
  await expect(page.locator('#rows tr')).toHaveCount(2);

  // Review Focus 4: same Cyrillic name, other case
  const dup = await startJoin(context, pin, 'аЯН', 2, errors);
  await expect(dup.locator('#name')).toBeVisible();
  await expect(dup.locator('.error')).not.toBeEmpty();
  await dup.close();

  await page.locator('#start').click();
  await expect(p1.locator('#hud')).toBeVisible({ timeout: 10_000 });
  await expect(p1.locator('#hud')).toContainText('0/10');

  await p1.bringToFront();
  await p1.keyboard.down('ArrowRight');
  await p1.waitForTimeout(500);
  await p1.keyboard.up('ArrowRight');

  // Review Focus 2: player reload keeps the game
  await p2.reload();
  await expect(p2.locator('#hud')).toBeVisible({ timeout: 10_000 });
  await expect(p2.locator('#screen')).toBeEmpty();

  // Review Focus 3: host reload keeps the dashboard
  await page.reload();
  await expect(page.locator('.pin')).toHaveText(pin);
  await expect(page.locator('#rows tr')).toHaveCount(2);

  page.once('dialog', (d) => d.accept());
  await page.locator('#stop').click();
  for (const p of [p1, p2]) {
    await expect(p.locator('.results')).toBeVisible();
    await expect(p.locator('.myplace')).toBeVisible();
  }
  await expect(page.locator('.podium')).toBeVisible();
  expect(errors).toEqual([]);
});
```

````markdown
## Edit questions

Edit `server/questions.json`: every room id (`f1r1`…`f1r5`, `f2r1`…`f2r5`) needs at least one question
`{ "q": "...", "options": ["A", "B", "C", "D"], "correct": 0 }` (`correct` is the index 0–3). Each player gets a
random question from the room's list with shuffled options. Run `npm test` to validate, then redeploy the server.

## Deploy

1. **Cloudflare (server)** — free account:
   ```bash
   cd server
   npx wrangler login
   npx wrangler secret put HOST_PASSWORD
   npx wrangler deploy            # prints https://key-house.<you>.workers.dev
   ```
2. **Vercel (site)** — push the repo to GitHub, import it in Vercel, set **Root Directory** = `client`,
   framework = Vite, and add the environment variable `VITE_SERVER_URL=https://key-house.<you>.workers.dev`.
3. Optionally lock CORS: set `ALLOWED_ORIGIN` in `server/wrangler.toml` to your Vercel URL and redeploy.
````
